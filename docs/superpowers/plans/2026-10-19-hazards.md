# Hazards Implementation Plan

> **For agentic workers:** Each task below is implemented by one subagent and reviewed by a separate read-only
> subagent; the orchestrator owns the plan, re-runs verification, reads the diff and commits. Steps use checkbox
> (`- [ ]`) syntax for tracking.

**Goal:** #37 — seeded comets that cross the belts and solar flares in M/B systems, each with a telegraphed
warning, a `hazards` difficulty setting (off / normal / harsh), fully deterministic.

**Architecture:** pure tables in `src/data/hazards.ts` + `TUNING` knobs; hazard state on `run.hazards` with its
own RNG stream (save v5 → v6); `src/sim/hazards.ts` schedules warnings, spawns comets as real `Rock`s flagged
`comet`, and drives the flare cycle; `update.ts` flies comets straight and applies flare damage; the level comes
in through `TickInput` like `assists`; renderer, HUD banner and audio read `run.hazards` and a new `hazard` fx.

**Tech Stack:** TypeScript, three.js, Vite, Vitest, oxlint/oxfmt

**Spec:** [`docs/superpowers/specs/2026-10-19-hazards-design.md`](../specs/2026-10-19-hazards-design.md)

## Global Constraints

- **`src/core`, `src/data`, `src/sim` stay pure:** no DOM, no three.js, no `Math.random`, no `Date`.
- **`src/data` stays a leaf.** `data/hazards.ts` imports nothing outside `data/`.
- **Determinism / isolation:** every hazard roll uses `run.hazards.rng`. With the level `off` (or `TickInput`
  without `hazards`) the sim must be byte-identical to `main`: `run.rng.s`, rock ids, the balance report.
- **`TickInput.hazards` defaults to `'off'`** so existing tests and `scripts/harness.ts` are unchanged.
- **Old saves load:** bump `SAVE_VERSION` to 6, one migration entry, `fromData` validation, a v5 fixture.
- Match the surrounding style: one header comment per module, `/** */` on exported functions and non-obvious
  fields, no comment noise. oxfmt (printWidth 120, single quotes, trailing commas).
- Every task ends with `npm run check` green. No new dependencies. Do not touch `scratch.md` or hand-edit
  `docs/balance.md`. Do not commit (the orchestrator commits).

## Review Focus

1. **RNG leakage** — any `run.rng` draw from scheduling or comet construction (`makeRock` draws `run.rng`!).
   Tasks 2, 3.
2. **Off is not off** — timers advancing, warnings surviving, or ids consumed while `off`. Task 2.
3. **Comet lifecycle** — never despawned when off, despawned while still inbound, shoved by ships, or the orbit
   settle bending its path. Task 2.
4. **Flare damage** hitting docked or dead ships, applying outside `reach`, or bypassing shields. Task 3.
5. **Save safety** — pre-v6 saves, malformed `hazards` causing a mid-tick throw. Task 1.
6. **Settings validation** — any string accepted as a level. Task 4.
7. **Per-tick allocation** in the hazard update or renderer overlay. Tasks 2, 4.
